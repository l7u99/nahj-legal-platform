# دقيقة قانونية | نهج القانوني
مشروع React + Vite مستقل. الواجهة والمخطط ودوال الخادم موجودة داخل هذه الحزمة.

## قبل النشر
1. أنشئي `.env.local` من `.env.example` وضعي Project URL وPublishable key فقط.
2. شغّلي `supabase/schema.sql` في SQL Editor للمشروع الجديد.
3. أنشئي مستخدم Auth للمسؤول ببريد إلكتروني خاص، ثم أضيفي صفه في `admin_users` باسم المستخدم `nahjadmin` والدور `owner` والحالة `active=true`.
4. انشري Edge Functions: `admin-login` و`submit-participation`. الدالتان تستقبلان طلبات عامة؛ اجعلي تحقق JWT معطلًا لهما، وتحققي من إعدادات الأسرار الافتراضية في Supabase.
5. لا تضعي `sb_secret_` أو `service_role` في ملفات الواجهة أو GitHub.

**حالة النسخة:** هذه حزمة تأسيس قابلة للبناء، وليست منصة إنتاجية مكتملة بعد. لوحة الإدارة الأساسية تنشئ مجموعات كمسودات وتنشرها/تؤرشفها، لكن محرر إدخال الأسئلة والخيارات، تحديد نافذة الأسبوع، ومراجعة أمنية واختبارات التكرار ومعدل الطلبات لا تزال مطلوبة قبل فتحها للجمهور. لا تعتمديها لاستقبال بيانات حقيقية قبل استكمالها واختبارها.
